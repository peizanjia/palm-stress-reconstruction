## 控制方程和求解区别

两种模型都满足 \(\operatorname{Div}_X\mathbf P=0\)。这里的大写 \(\mathbf P\) 是第一 Piola–Kirchhoff **应力张量**，它的散度为零给出**三条**平衡方程。

- **可压缩**只有位移 \(\mathbf u\) 是独立未知量。每个 Newton 步由位移计算 \(\mathbf F=\mathbf I+\nabla_X\mathbf u\) 和 \(J=\det\mathbf F\)，再由本构得到应力并更新位移。有限体积模量允许 \(J\) 偏离 1。越接近 \(\nu=0.5\)，体积刚度越大，低阶纯位移单元越容易表现得过硬。
- **不可压缩**同时求位移 \(\mathbf u\) 和标量压力 \(p\)。当前构形下可写成 \(\operatorname{div}_x(\mu\mathbf B-p\mathbf I)=0\)，另加 \(J=1\)。所以是**三条平衡方程加一条体积约束**。每步要联立更新位移和压力，压力通过梯度进入平衡方程。这个 \(p\) 是体内维持等体积的乘子，压头接触压力由边界接触条件决定。

## 这种硅胶有多接近不可压缩？

**近不可压缩是合理的待验证假设。** Wesitru C-0030 的公开资料没有给出泊松比或体积模量。其他 PDMS 配方有实测例子，Sylgard 184 和 182 的泊松比分别约为 **0.4950** 和 **0.4974**。这些数据支持做近不可压缩对照。当前采用的 **0.45 是试算值**，C-0030 自身的可压缩性仍待测量。 [C-0030 厂商资料](https://www.wesitru.com/productinfo/1155533.html) · [PDMS 泊松比实测](https://pubmed.ncbi.nlm.nih.gov/30633288/)

对后续反演，建议先用已归档的 \(\nu=0.45\) 数据做**同本构核查**，再用这次共同收敛区间内的混合结果测试**本构不匹配会使恢复出的接触力偏多少**。这次对照已经说明，即使压头行程相同，体积假设也会改变反力和接触区外的隆起。

## 1. 给定顶面完整位移，如何求解

在你设定的近似下，顶面材料点 \((r,\theta,H)\) 移到 \((r,\theta,h(r,\theta))\)。因此顶面的三个给定位移分量是

\[
u_r=0,\qquad u_\theta=0,\qquad u_z=h(r,\theta)-H.
\]

底面和侧面仍取 \(\mathbf u=0\)。顶面边缘应与固定侧壁衔接，因此 \(h(a,\theta)=H\)。

### 可压缩 Neo-Hookean

直接做一次**位移控制的非线性有限元计算**。把边界节点的三个分量赋值后消元，Newton 迭代只更新内部自由度。每次由位移计算 \(\mathbf F=\mathbf I+\nabla_X\mathbf u\)、\(J=\det\mathbf F\) 和应力 \(\mathbf P(\mathbf F)\)，令内部自由度上的残差为零。实际可将目标位移按 \(0\to100\%\) 分步施加，跟踪平衡分支，并在迭代中检查 \(J>0\)。

小变形线弹性下，适当的边界数据和正定弹性模量给出唯一解。有限变形下，全狄利克雷条件给出了完整的边界数据，但全局存在性和唯一性仍取决于变形幅度、材料以及平衡分支。Newton 收敛表明找到了一个离散平衡。

求解后，约束自由度上的残差给出节点反力。也可在当前顶面由 \(\mathbf t=\boldsymbol\sigma\mathbf n\) 提取牵引。若要把它解释为**无摩擦压头的接触力**，还要检查接触区内切向牵引接近零、法向力为压缩，接触区外牵引接近零。强制顶面横向位移为零本身可能需要切向反力。这个检查可以直接衡量你的近似对反演载荷的影响。

### 不可压缩 Neo-Hookean

**先算一个积分，再决定能不能启动求解。** 由于底面和侧面固定、顶面覆盖同一个圆盘 \(A\)，给定的顶面必须满足

\[
\int_0^{2\pi}\!\int_0^a [h(r,\theta)-H]\,r\,dr\,d\theta=0.
\]

例如，顶面有一块下陷，其余部分完全平坦，那么整体体积减少，**严格不可压缩问题无解**。减小载荷步或加密网格都不能改变这个相容性条件。凹陷与隆起恰好平衡后，还要检查变形是否允许，并求解平衡。

求解时，给定边界位移，联立更新内部位移 \(\mathbf u\) 和压力乘子 \(p\)。两组残差分别来自**三条力平衡方程**和**一条 \(J=1\) 约束**。全位移边界下，若 \((\mathbf u,p)\) 是解，则 \((\mathbf u,p+c)\) 具有相同变形，也满足内部平衡，因为常数静水压力的梯度为零。这个常数会改变顶面的绝对法向反力。

计算时可先设平均压力为零，获得一个代表解。若有一块已知的无载自由表面，或已知整个顶面的竖向合力，就可用它来确定压力常数。**平均压力取零是数值定标，绝对接触力还需要物理定标。**

## 2. 把 \(\operatorname{Div}\mathbf P=0\) 化成调和方程，可行吗？

这里有两种不同的 \(P\)。

**如果你指的是应力张量 \(\mathbf P\)**，平衡式是 \(\operatorname{Div}_X\mathbf P=0\)。把它的第 \(i\) 行设为 \(\nabla_X\phi_i\)，确实会得到 \(\Delta_X\phi_i=0\)，但你同时添加了一个条件：**每一行应力都无旋**。平衡只要求每行无散，这两个条件互相独立。

有一个直接的反例。对矩形体施加全边界位移，使其产生有限变形 \(u_x=u_y=0,\ u_z=bXY\)，其中 \(b\ne0\)。这时 \(J=1\)，可压缩 Neo-Hookean 给出 \(P_{13}=\mu bY\)、\(P_{12}=0\)，且整个应力场满足 \(\operatorname{Div}\mathbf P=0\)。然而
\[
\partial_Y P_{13}=\mu b,\qquad \partial_Z P_{12}=0.
\]
两者不等，所以第一行无法写成某个标量势的梯度。这个例子本身就是一个**有弹性解、却会被应力有势假设排除**的全狄利克雷问题。

边界条件的判断也吻合你的直觉。若采用这个势表示，\(\partial_N\phi_i\) 对应的是第 \(i\) 个**名义牵引分量**，所以给牵引才对应势的 Neumann 条件。你的反问题给的是位移，而牵引正是要算的量。把已知位移直接赋给 \(\phi_i\)，不能把位移边界传递给原弹性问题。

**如果你指的是不可压缩模型的标量压力 \(p\)**，则存在一条有用的压力–Poisson 路线。对小变形、常剪切模量、无体力的不可压缩弹性，
\[
\mu\Delta\mathbf u-\nabla p=0,\qquad \nabla\cdot\mathbf u=0.
\]
对平衡式取散度，得到 \(\Delta p=0\)。你的调和方程直觉在这里成立。难点是，**\(p\) 的边界数据仍依赖未知的位移导数**，给了边界位移也无法直接写出这些导数。因此可把压力方程当作耦合求解的一部分，或用它消元、预处理。到了有限变形，压力一般满足 \(\Delta_x p=\mu\,\operatorname{div}_x\operatorname{div}_x\mathbf B\)，右端也随未知变形变化。

## 3. 为什么有限差分能迭代，却可能解不到原问题？

这里要分开判断**迭代是否收敛**和**迭代求的是哪一个问题**。

- 矩形域上，标准五点差分的 Laplace 方程给定完整且适当的 **Dirichlet 边界值**，离散解通常唯一，经典 Jacobi 或 Gauss–Seidel 可以收敛。即使你把错误的物理量填成边界值，它也可能顺利收敛，得到一个调和场。这个场仍需另行满足原弹性本构和位移边界。
- 若给的是**纯 Neumann 条件**，Laplace 方程要求总边界通量为零，解还差一个任意常数。通量不相容时，没有能使残差归零的解。通量相容时，也要固定常数或施加零均值后再求解。

对你已有的合成数据，最直接的核查是用**同一网格和可压缩本构**做两次全狄利克雷求解。第一次用快照里的**完整顶面节点位移**，检查能否恢复原正问题的节点反力。第二次只用高度并设置 \(u_r=u_\theta=0\)，再比较法向合力、接触区外牵引和顶面切向反力。这样就能把**求解实现的误差**和**忽略横向位移造成的误差**分开。 [已归档快照的字段说明](../../docs/stage-01-forward-model/task-03-inverse-reference.md)
