# 分析不可压与可压计算区别

以下为项目相关的用户消息、Agent 进度和答复。工作区链接已改为仓库相对路径。初始附件另见[研究说明](research-brief.md)。

## 交互 1

**用户**

本项目不可压，边界条件设置为底面侧边全固定有解吗，相比已经实现的可压计算流程有什么区别，只读

**Agent 进度**

我会只读核对项目里的边界条件、材料模型和求解流程，再判断严格不可压时是否有解，以及现有可压流程会有哪些变化。

**Agent 进度**

代码里已经有球压入的位移–压力混合分支。我会核对已有日志，确认哪些加载步已经收敛，并区分总保体积和局部体积误差。

**Agent 答复**

**有解。对本项目的局部球压入，底面和侧面可以保持三向全固定。** 顶面只有一部分与压头接触，其余区域仍可隆起。严格不可压要求每一点的体积比 \(J=\det F=1\)。在顶面仍能表示为高度场时，整个顶面的隆起体积必须恰好补偿下陷体积。若额外规定整个顶面只能下移或留在原高度，且有一片区域确实下移，就与保体积条件冲突。这个判断针对边界条件的相容性，深压入能否持续取得平衡还要看接触几何和数值收敛。[边界条件与默认参数](../../config/indentation_config.m#L3)

| | 现有可压流程 | 不可压流程 |
|---|---|---|
| 材料与未知量 | 只求位移 \(\mathbf u\)。默认 \(\nu=0.45\)、\(K=290\) kPa，允许 \(J\) 偏离 1。 | 同时求位移 \(\mathbf u\) 和体积约束的拉格朗日乘子 \(p\)。连续模型要求 \(J=1\)，\(p\) 由平衡与体积约束共同确定。 |
| 球压入求解 | 按压头行程递增，以无摩擦罚接触计算反力。 | 沿用相同的固定边界、接触和行程控制。Newton 方程增加位移–压力耦合，当前六节点楔体采用压力稳定化，整体体积守恒到求解精度，局部仍有 \(J-1\) 误差。 |
| 顶面应力反演 | 用位移梯度和可压本构恢复应力。 | 恢复应力还需要求得的 \(p\)。它是材料内部的体积约束乘子，压头接触压力仍由罚接触单独计算。 |

[可压本构](../../docs/forward-method.md#L7) · [混合装配](../../src/+palm/+fem/assemble.m#L30) · [应力与接触压力导出](../../src/+palm/+dataset/snapshot.m#L29)

**当前代码和结果已经支持这个判断。** `run_indentation` 已有混合分支，由 `cfg.pressureStabilization` 启用。给定顶面牵引的 `run_forward` 仍走纯位移流程，配置要求 \(\nu<0.5\)，而把 \(\nu\) 调近 0.5 有体积锁死风险。[球压入入口](../../run_indentation.m#L19) · [给定牵引配置校验](../../src/+palm/validateConfig.m#L7)

只读检查时，粗网格混合算例已在 **0.52 mm** 压头行程下收敛，反力为 **0.191 N**，总体积变化约 \(5.5\times10^{-12}\ \mathrm{mm^3}\)，局部 \(J-1\) 的体积加权 RMS 约 **0.19%**。这验证了同一固定边界下的浅压入离散解。当时细网格混合日志只记录到零载步，完整行程的同网格反力、顶面高度和应力差异尚无结果可比。本次未运行求解或修改文件。[粗网格日志](../../results/stage-01-forward-model/task-04-compressibility/20261120_comparison_v1/logs/incompressible_coarse.log) · [细网格日志](../../results/stage-01-forward-model/task-04-compressibility/20261120_comparison_v1/logs/incompressible.log)

## 交互 2

**用户**

现在主要问题的有限元计算过程的加速，得出结果的速度要能用于实时反馈控制，有什么技术路线

**Agent 进度**

我会先看项目现有的网格、求解耗时记录和高度输出流程，再按实时反馈的需求评估哪些计算可以移到离线，哪些适合留在控制周期内。

**Agent 答复**

本项目最适合的路线是 **离线用三维有限元生成标定数据，在线从顶面高度估计接触合力和位置**。第一版闭环可以先控制法向合力 \(F_z\)，需要定位时再加接触中心。完整压力场可以低频更新，也可以在控制确实依赖局部压力时再加入快环。

现有耗时说明了为什么要这样做。任务 04 的 `ν=0.45` 细网格算例完成 19 个载荷步用了 **200.7 s**，平均约 **10.6 s/步**。混合不可压细网格用了 **450.6 s**，在约 **3.07 mm** 行程处因 Newton 失败停止。计时包含网格准备和每步后处理，尚没有装配、线性求解和高度采样的分项耗时。如果闭环目标取 **100 Hz**，整条链路每周期只有 **10 ms**，还要留给相机、传输和控制。因此，现阶段不宜把逐帧三维 Newton 求解放进快环。[可压运行日志](../../results/stage-01-forward-model/task-04-compressibility/20261120_comparison_v1/logs/compressible045.log) · [不可压对照](../../docs/stage-01-forward-model/task-04-compressibility.md#L53) · [计时代码](../../run_compressibility_case.m#L30)

| 技术路线 | 适用工况 | 本项目怎么做 |
|---|---|---|
| **查表或低维回归** | 已知球头，单点接触，优先控制合力 | **首选。** 如果编码器能给压头行程，先做行程–反力插值。如果在线只有高度图，用局部下陷、接触尺度、位置和周围隆起作为输入，输出 \(F_z\) 和接触中心。现有 `height_mm` 与 `force_N` 可以直接做原型。 |
| **预计算柔度矩阵 + 低维载荷反演** | 压头形状未知，或需要估计粗分辨率压力分布 | 在多个预压状态离线线性化混合有限元，得到小幅载荷变化到测量高度变化的映射。在线只求少量压力系数，加非负和正则化约束，再积分得到合力。接触区变化大时，按工作点切换模型。 |
| **非线性降阶有限元** | 控制确实需要较大变形下的压力场，前两条精度不足 | 对位移和压力建立混合降阶基，并对单元内力和接触做超降阶。只压缩未知量、仍遍历全网格装配，在线收益会受限。训练范围还要覆盖接触区变化和卸载。 |
| **优化全阶求解器** | 加快离线样本生成，或做低频校正 | 先量出装配、稀疏求解、回溯和后处理各占多少，再优化。现有代码已有历史步预测和自适应减步。可进一步复用稀疏结构、精简输出，并在确认热点后考虑 MEX 或混合块预条件。 |

[已有高度、合力和压力数据格式](../../docs/stage-01-forward-model/task-03-inverse-reference.md#L21) · [现有 Newton 流程](../../src/+palm/+indent/advance.m#L19)

**我建议先做一个单球头法向力闭环。** 用现有中心和偏心两组快照搭起离线回放，比较“行程插值”和“高度特征估力”。混合不可压数据用于已收敛的行程范围，随后用真实硅胶和同步测力数据校准。验收时按整条未参与拟合的加载和卸载轨迹测**力误差、端到端延迟、P99 和超时率**。当前有限元是准静态模型，如果同一深度的力随加载速度或加载历史明显变化，再给在线估计器加速度或短时历史输入。这样能先回答闭环最关键的问题：**在相机和控制器的实际时序下，估出来的力是否够准、够及时。** [现有中心与偏心快照覆盖范围](../../docs/stage-01-forward-model/task-03-inverse-reference.md#L3)
