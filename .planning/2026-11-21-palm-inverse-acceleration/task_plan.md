# 曲面约束反演与加速

1. 曲面约束求解及可解性检查（完成）。0.50 mm 平滑版完成中心和偏心 40 帧，保留较弱平滑和未平滑的停止日志。
2. 调研（完成）。核查能量 PINN、接触互补和有限元投影降阶的原始资料。
3. 原型采样训练（完成）。比较能量 PINN、同结构力监督消融、无训练 Ritz 与 PCHIP。生成六条新轨迹，修正位置、球头半径和量测噪声下的误差。
4. 验收（完成合成原型）。记录力误差、局部接触牵引限制与单帧计时，给出后续扩展采样和实物控制验收方案。

## 跨形状、位置、姿态和深度

1. 实现球形、椭球及圆角方形压头的统一解析间隙、法向及切线。通过有限差分和等半径球对照。
2. 固定种子 826，以整条轨迹划分。36 条名义训练候选、9 条开发、9 条联合测试。另各 4 条新形状、中远偏心、大倾角、深压入和配对细网格。把候选中平面角 60°–100° 的整条轨迹从训练中留作角度挑战，测试标签不选超参数。
3. 以仅高度输入比较非神经回归、图像力估计和离散能量 PINN。记录各轨迹力偏差、MAE、相对误差、最慢推理及 Gauss 点 J。选模型只用开发轨迹。
4. 对 25 µm 加噪、分辨率变动和训练域外单因素挑战单独报结果。目标沿用 MAE ≤0.05 N、深步误差 ≤5%、P95 ≤5 ms，区分达到目标与参考模型误差。

四项均已执行，两轮采样 98 条，另有顶面力积分和两种推理硬件复核。未达标分组与模型适用范围已登记在泛化报告。

## 套磁邮件图件

1. 盘点旧有限元图、保存的泛化轨迹、推理表和权重，选择可独立复核的留出图件。
2. 回放留出轨迹导出正算变形网格，调用现有检查点导出 PINN 重构位移。用原表核对两种合力。
3. 用代码生成变形、载荷–行程、精度、有限元对照与邮件总览。技术流程以同一布局输出 SVG 和原生 draw.io。
4. 检查中文字体、字段口径、图面可读性、矢量和 XML 格式，并交付复现入口。
